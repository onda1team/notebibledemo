# 주의열매 코넬 여백성경

성경 본문과 여백을 함께 펼쳐 읽고, 키보드 메모·손글씨·주보를 계정별로 저장하는 웹앱입니다. 브라우저 화면과 인증·동기화 서버를 하나의 Cloudflare Worker로 빌드하며, D1에 장별 기록을 보관합니다.

## 실행과 검증

Node.js 24가 필요합니다.

```sh
npm ci
npm run build
npm test
npm run dev
```

`npm run dev`는 테스트 계정과 메모리 데이터베이스를 사용하는 화면 개발용입니다. 구글 로그인 검증과 실제 배포 절차는 [배포 안내](docs/DEPLOYMENT.md)를 따릅니다. OAuth 클라이언트와 서버 환경 설정 없이 구글 로그인이 활성화되지는 않습니다.

## 저장 방식

- 수정 내용은 계정별 기기 초안으로 먼저 저장하고 서버로 전송합니다.
- 서버는 장별 버전을 확인하여 오래된 기록의 무조건 덮어쓰기를 막습니다.
- 같은 장의 수정이 겹치면 양쪽 기록을 비교·백업하고 사용할 기록을 선택할 수 있습니다.
- 저장 도중 남은 초안은 복구 목록에서 확인합니다. 과거 브라우저 저장 키를 임의로 지우지 않습니다.
- 같은 로그인 계정으로 접속해야 기기 간 개인 기록이 연결됩니다. 이메일 문자열만으로 계정을 합치지 않습니다.

## 배포 구분

GitHub 저장소 주소와 앱 접속 주소는 다릅니다. 이 앱은 서버와 데이터베이스가 필요하므로 GitHub Pages로만 배포하지 않습니다. GitHub Actions는 검증만 실행하며, 독립 Worker 배포는 [Cloudflare 설정](docs/DEPLOYMENT.md)을 완료한 뒤 진행합니다.

기존 비공개 Sites 배포는 별도로 관리합니다. 독립 Worker로 옮기면 새 주소와 데이터베이스가 사용되므로 기존 기록 이전을 별도로 확인해야 합니다. 배포 소스에는 개인 필기 백업과 인증 비밀 값을 포함하지 않습니다.
